Booklet size comparison

How the viewer scales each page size on screen — true to physical proportion above a legibility floor, so smaller formats read as smaller without becoming hard to read. Height scale = max(0.65, heightIn / 11), capped at 1, computed from each individual page's own height regardless of layout.

Horizontal layout — left / right pages

Vertical layout — top / bottom pages

The two 11″-tall horizontal formats render at full height and differ only in width (their true proportion). 5.5×8.5 renders at its true ~77% since that's above the floor; 4.25×5.5 is floored at 65% rather than its true ~50%. Vertical layout uses the same four physical sizes turned on their side (so a 5.5×8.5 booklet becomes an 8.5×5.5 page, top/bottom paired) — StPageFlip has no vertical flip mode, so the actual viewer renders this as a normal horizontal book with the whole thing rotated 90° and each page's content counter-rotated to stay upright.
